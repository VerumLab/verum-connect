# @verumlab/connect-protocol

The Verum Connect wire protocol, shared by the dapp and wallet sides: NIP-44 encryption, nostr events, the relay pool, envelopes, pairing links and typed connect codes.

Most apps use [`@verumlab/connect-dapp`](https://www.npmjs.com/package/@verumlab/connect-dapp) or [`@verumlab/connect-wallet`](https://www.npmjs.com/package/@verumlab/connect-wallet) instead; this package is what they build on, and what another implementation can check itself against.

```bash
npm install @verumlab/connect-protocol
```
